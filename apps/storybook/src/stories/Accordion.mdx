# Accordion

## Overview

An **Accordion** is an expandable and collapsible list of sections used to organize blocks of content into compact groups. Compose `<AtlAccordion>` with one or more `<AtlAccordionItem>` subcomponents to place rich HTML or interactive Design Atlas components inside each panel.

## Technical implementation

### Events

| Component | Event | Payload | Description |
| --- | --- | --- | --- |
| `AtlAccordionItem` | `toggle` | `CustomEvent<{ open: boolean }>` | Dispatched with the next open state after a heading click. |
| `AtlAccordion` | `click`, `mouseover`, `mouseenter`, `mouseleave` | Native `MouseEvent` | Forwarded from the root `<ul>` container. |
| `AtlAccordionItem` | `click`, `focus`, `blur`, `keydown`, `mouseover`, `mouseenter`, `mouseleave` | Native DOM event | Forwarded from the heading `<button>` element. |

### Props

| Component | Prop | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `AtlAccordion` | `align` | `"start" \| "end"` | `"end"` | Placement of the chevron icon inside each heading. |
| `AtlAccordion` | `outline` | `boolean` | `true` | Displays the outer border and rounded corners. Set to `false` to remove the outer border while preserving internal spacing. |
| `AtlAccordion` | `type` | `"multiple" \| "single"` | `"multiple"` | `"multiple"` allows any number of items open at once; `"single"` closes other items when one opens. |
| `AtlAccordion` | `disabled` | `boolean` | `false` | Disables all child `AtlAccordionItem` headings without overwriting each item's own `disabled` prop. |
| `AtlAccordionItem` | `title` | `string \| undefined` | `undefined` | Heading text displayed inside the trigger button. |
| `AtlAccordionItem` | `open` | `boolean` (bindable) | `false` | Controls whether the section is expanded (`bind:open`). |
| `AtlAccordionItem` | `disabled` | `boolean` | `false` | Disables interaction for this individual section. |
| `AtlAccordionItem` | `ariaLabel` | `string \| undefined` | `undefined` | Accessible label for the heading button when no visible title is provided. |
| `AtlAccordionItem` | `ref` | `HTMLButtonElement \| null` (bindable) | `null` | Reference to the underlying heading `<button>` element. |
| `AtlAccordionItem` | `id` | `string` | auto-generated | Identifier for the `<li>` element (derives `{id}-button` and `{id}-content`). |

### Slots

| Component | Slot | Description |
| --- | --- | --- |
| `AtlAccordion` | `default` | Composed `<AtlAccordionItem>` children. |
| `AtlAccordionItem` | `title` | Custom heading markup inside the trigger button (falls back to the `title` prop). |
| `AtlAccordionItem` | `default` | Panel content—accepts text, rich HTML, or any Svelte component. |

## Keyboard Navigation

| Key | Action |
| --- | --- |
| `Tab` / `Shift + Tab` | Moves focus into and out of the accordion and through focusable elements inside open panels. |
| `Enter` / `Space` | Expands or collapses the focused accordion section. |
| `ArrowDown` | Moves focus to the next enabled accordion heading (wraps to first). |
| `ArrowUp` | Moves focus to the previous enabled accordion heading (wraps to last). |
| `Home` | Moves focus to the first enabled accordion heading. |
| `End` | Moves focus to the last enabled accordion heading. |
